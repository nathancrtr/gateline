# Candidate A — Design rationale

**Theme: warm light ("paper").** Single theme, committed. I ruled out cold dark explicitly (the brief names `#0a0e11` as the aesthetic we are leaving) and a warm-dark would have competed with the editorial-serif reading surface for warmth. A warm-paper ground (`#faf7f1`) does the cozy work: it lets the reading surface (`#fdfbf6`, one shade warmer) read like a page, not a panel, and it lets tinted status chips sit on a real ground instead of floating on black.

**Type roles (A3).** Three named roles, three families after iteration:
- **Inter** (sans) — *all* headers, chrome, UI, labels, body copy outside the reading surface. Differentiation from body comes via weight (semibold/bold), size, tracking, and color — not via a different face. The "Gate" wordmark, the inbox "Inbox" wordmark, the "7 waiting" numeral, every screen's H1, section kickers, and the genesis commit message on New Run are all Inter semibold.
- **Newsreader** (text serif) — *the artifact reading body only* (run-detail.html). This is the one place a serif is clearly justified: long-form reading. Measure-capped ~76ch, leading 1.68, 16.5px. Within the reading surface the body paragraphs, the italic lead, and the blockquote are Newsreader; the doc's own h1/h2 are Inter sans, giving a clean sans-headings + serif-body reading frame.
- **JetBrains Mono** — slugs, paths, `state.yaml`, code, ids, tabular numerals.

> **Iteration note — Fraunces removed.** The first pass used Fraunces italic serif for all headers, chrome, the wordmark, section kickers, and the genesis commit message. The product owner's feedback: the italic serif made the UI feel "literary" — an old-Tumblr / library aesthetic — which conflated the "cozy reading environment" reframe with "library aesthetic." Those are different things. Fraunces was removed entirely (font import dropped); every former Fraunces surface now uses Inter. The serif is now reserved for the reading body alone, so the warmth comes from the paper ground, the terracotta accent, the generous spacing, and the serif reading body — not from italic serif headers. The system still clears A3 (≥2 distinct type roles by *purpose*): sans for chrome, serif for reading, mono for code.

**Signature motif.** A gate **sigil** — two posts plus a crossbar as a small inline SVG — recurs in the chrome of all four screens and as the empty-state mark (the warmth lever, restrained to one gesture). The second motif, used on *one* surface only, is a faint **blueprint grid** behind the New Run live-preview aside, so the preview reads as a page proof rather than a debug log.

**Genesis commit chip.** The hero element on New Run. I rendered it as a confident headline, not a `<pre>`: the commit message is set in Inter semibold at 21px (`state(csv-importer): staged by Nathan Carter`), with the `client-key` UUID dropped to a small mono subline so it reads as provenance rather than payload. A filled-accent status dot with a soft 4px tinted halo carries "ready"; an author/committer line beneath carries the identity. The whole chip sits on the gridded, tinted preview "page." (In iteration this was migrated from Fraunces italic to Inter semibold per the product owner's feedback — it still reads as a considered hero, just no longer literary.)

**Reading surface treatment.** Run Detail's artifact pane is the centerpiece and the place I earn the reframe. It is **not a card** — no border, just a warmer paper ground, 40–56px padding, a 76ch measure cap, Newsreader at 16.5/1.68. The full typographic range is exercised: italic H1 + italic lead, italic-serif H2s against Inter-weight H3s, code blocks on a tinted warm ground, a left-ruled blockquote with a mono cite, a quiet-bordered table, task-list checkboxes, and an `ASSUMPTION:` callout. The header metadata is a Raycast-style **MetadataRail** docked to the right so it never competes with the prose.

**Reference board — what I stole.** Stripe (italic-serif hero + large real numbers — the "7 waiting" numeral, the "Stage a run" headline, the genesis commit message). GitHub Primer (tinted status chips everywhere; cool near-black `#24201c` ink; layered ring + soft-drop shadows on the decision card and the preview aside). Raycast (MetadataRail on Run Detail). Vercel Geist (named type roles; the 4/6/8/12/16 radius ladder — inputs 6, chips 8, cards 12, fullscreen preview 16). Sentry (left-edge status rail on inbox rows). Linear (display-cut headings against a text-cut body).

**Anti-patterns.** A1 — three distinct wrappers: flat 1px-line task board, accent-rail + tinted-ground + lifted-shadow NeedsYou card, borderless reading page. A2 — radius ladder, not one radius. A3 — three roles above (sans chrome / serif reading / mono code, distinguished by purpose). A4 — scan (portfolio), comfortable (inbox), reading (artifact, generously spaced), evidence (mono `state.yaml`, dense). A5 — every chip carries a glyph (`✓`/`✕`/`·`), a shape (filled dot vs. hollow ring vs. dashed), and a fill style in addition to hue; bounced gates are dashed + struck-through, not just red; pending gates are dashed-outline. No keyboard hints, no pulsing glow (the pending G2 gets a static 2px tinted ring — the class was renamed from `.pulse-ring` to `.static-ring` so the name reflects the intentionally non-animated behavior), no cold-dark identity, `prefers-reduced-motion` collapses the skeleton shimmer.

**Iteration fixes (review feedback).** (1) Removed Fraunces entirely — see the type-roles note above. (2) Darkened `--faint` from `#a89f95` (~2.45:1 on the paper ground, failing AA for the 11.5–12.5px packet/footer text) to `#756b61` (~4.81:1, clearing WCAG AA for small text). (3) Fixed the task-list checkboxes in the reading surface: they now render as a fixed 15px square (`box-sizing:border-box`), aligned with the text baseline via flexbox, and offset from the container's left edge so the checkbox no longer runs into the reading-frame boundary.
