current against field evidence (v0.2), adversarially reviewed
([review-01.md](review-01.md), round 1: request-changes), the findings applied
(round 2), and the result synthesized into the executable
[docs/INTEGRATION-PLAN.md](../../docs/INTEGRATION-PLAN.md).

Field evidence consulted: the two hand-executed integrations' retros
(maintained outside this repository, per the flowback rule) and this repo's
issue tracker (#42–#43, #48–#55).
